# Star Wars FFG для Foundry V14 — русский интерфейс

Форк StarWarsFoundryVTT/StarWarsFFG 2.0.4 (upstream `4b87fe1`). Исправления совместимости адаптированы из [PR #2280](https://github.com/StarWarsFoundryVTT/StarWarsFFG/pull/2280), автор salohcin714, состояние `a3d0e66`. При переносе сохранены актуальные модели данных, исправления экипировки, импорта и создания персонажей из 2.0.4.

## Установка

Манифест для установки в Foundry:

```
https://raw.githubusercontent.com/DarkReef/StarWarsFFG/v14-ru/system.json
```

Идентификатор системы сохранён: `starwarsffg`. Установка этого форка заменяет другую установку StarWarsFFG в том же каталоге данных. Для нового мира выберите **Star Wars FFG — V14 (RU)**. Для существующего мира перед переходом с V13 сохраните резервную копию вне активного каталога данных; обратный переход требует восстановления этой копии.

Выберите русский язык в Foundry. Встроенный перевод содержит все 1103 строки исходного английского словаря и 53 дополнительных строки интерфейса. Модуль `ru-ru` рекомендуется для перевода самого Foundry; для перевода системы он не обязателен. Старые строки StarWarsFFG из `ru-ru` не перекрывают словарь форка.

Для русской сортировки навыков включите «Сортировать навыки по переведённым названиям» в настройках локализации системы. В переводе используются «ПО» (пункты опыта), «ЯМ» (ячейки модификаций), «Сила» (характеристика Brawn) и «рейтинг Силы» (Force Rating).

## Что переведено

Листы всех типов персонажей и предметов, навыки, характеристики, настройки, окно броска, управление группой, состояния, мастер создания персонажа, подсказки и сообщения. Для кириллицы добавлены системный шрифт, переносы длинных подписей и многострочные вкладки. Шрифты символов костей и значки сохранены.

В исходной системе нет компендиумов. Имена и описания импортированных предметов, талантов, видов и приёмов Силы остаются на языке исходных данных. Babele нужен для перевода этих компендиумов, а не интерфейса. В этом выпуске словари компендиумов Babele не поставляются.

## Проверка и ограничения

Целевая локальная версия Foundry: 14.368. Проверены синтаксис модулей, адаптеры эффектов и чата, перенос эффектов, правило экипировки, полнота словаря, сохранение подстановок и компиляция всех HTML-шаблонов (`npm test`).

Полный игровой прогон и визуальная проверка листов в работающем браузере в этой сессии не выполнены: средство управления Windows-браузером остановилось из-за неподдерживаемой проверки URL. Выпуск предварительный. Параметр `verified` манифеста указывает целевую версию для установки и не заменяет игровой тест.

Сохраняется устаревший интерфейс ApplicationV1. Некоторые предупреждения Foundry об этом ожидаемы; перевод интерфейса не означает перевод технических журналов. В исходном проекте есть ошибки ESLint, поэтому общий lint отдельно сравнивается с исходной 2.0.4; они не скрываются изменением правил.

## Разработка

Node.js 24: `npm ci`, затем `npm test`. Основная ветка форка — `v14-ru`; оригинальная `main` сохранена для сравнения. Файлы Foundry, данные миров, лицензия Foundry и сторонние наборы в репозиторий не включены.
